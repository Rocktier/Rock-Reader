## 三、本版具体改了什么

### 3.1 摘录多色（P0-1）

- 长按正文存摘录时，面板里多了 5 个颜色可选；颜色随主题明暗走（夜间用更亮的那组）
- 摘录列表每条左侧一条色标，颜色就是当时选的那支
- 老摘录（升级前存的）统一按默认色显示，不会空白

### 3.2 书签备注（P0-2）

- 书签列表每项右侧新增「✎」，点开就地写备注，取消/存下
- 保存只改那一行，不会整列表重建

### 3.3 全书剩余时间（P0-3）

- 底栏在「本章还剩…」下面加一行「全书还剩约 N 小时 M 分」
- 与全书进度**同一口径**（按已读百分比反推），不会出现两个数字互相矛盾
- 字数还没量完时这一行自动不显示，不会冒出「约 0 分钟」

### 3.4 成就徽章（P0-4）

- 统计页底部新增徽章区：连续阅读天数、累计阅读时长、读完本数等里程碑
- 未解锁的显示当前进度条；全部数据本地算，不新增表、不联网

### 3.5 书架卡片显示作者（P0-5）

- 书架「继续阅读」卡与网格卡都显示作者（此前 EPUB 作者提取了却不显示）
- TXT / Markdown / HTML 此前作者恒空，现在会从文件名里探测；实在没有就显示格式，不留白

### 3.6 MOBI 编码修复（缺陷修复）

- 修前：MOBI 的编码字段解析了但**没被用来解码**，UTF-16 / GBK 的书会静默显示乱码且不报错
- 修后：按文件声明的编码解码；遇到不支持的编码会明确提示，而不是给一堆乱码

### 3.7 三处按反馈修正

1. **摘录色标收短**：原先撑满整行（含章节行与边距），看着像分隔线；改成一行高度
2. **正文可划词**：长按能拖选文字 + 系统菜单复制（此前只能触发摘录）
3. **摘录快照可裁剪**：长按定格的是整页，现在能在面板里手动删到只剩想要的那句

## 四、技术备注（给以后接手的人）

- **数据库迁移**：`highlights` 加 `color`、`bookmarks` 加 `note`，都是幂等 `ALTER TABLE`
  （照 `group_name` / `char_count` 的既有套路）。老库升级不会丢数据，模拟器实测启动无崩溃。
- **划词选中的能力边界（已查 SDK，别再试）**：
  - `SelectionContainer` 在本工程 compileSdk 20 下**编译不过**
    （`ArkTS: Cannot find name 'SelectionContainer'`，ERROR 10505001）
  - `onTextSelectionChange`（取选区文本）与 `editMenuOptions`（往系统菜单塞自定义「摘录」项）
    **都是 API 26 起**，本工程 20 ⇒ 用不了
  - ⇒ 只有 `Text.copyOption(CopyOptions.LocalDevice)` 这一条路可用；
    要「摘录正文里某一句」，只能靠面板里手动裁剪快照
- **出包脚本坑（2026-10-30）**：`build-release.ps1` 因 `$ErrorActionPreference = "Stop"`
  + `node ... 2>&1`，把 hvigor 的 **WARN（走 stderr）** 当错误引爆，
  表现为「6 秒 Failed :entry:default@CompileArkTS」，实际构建没跑完。
  已改成经 `cmd /c` 重定向 + 只看退出码。**两仓的脚本都要同步这个修法。**
