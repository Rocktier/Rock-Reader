## 更新说明正文（直接粘贴这段）

```
【新增】男声朗读
朗读面板新增男声音色「凌飞哲」。首次选用需你确认后，由系统语音服务下载音色包
（消耗流量），下载进度实时可见，之后即可离线使用；下载失败可重试。

【优化】自动续听
朗读过程中离开阅读页再返回，自动接着朗读，不用再按一次播放。

【优化】平板与横屏排版
设置、关于、统计、隐私四个页面在平板或横屏下版心居中，不再拉伸满屏。

【优化】设置面板更易用
排版设置内容较多时，也能一键关闭（面板右上角 ×）。

【优化】读屏适配
完善了朗读控制、书签、目录、搜索等区域的无障碍朗读支持。

【隐私】权限不变，仍为零
本应用不申请任何权限。音色下载由系统语音服务执行，
仅在你主动确认下载时才联网；朗读合成全程离线。
```

正文共 6 条 / 约 260 字。四条设计取舍说明（不上传，给党哥自己看）：

1. **音色下载把「消耗流量」和「确认」写进正文**：这是家族「非主动联网」口径的
   UI 义务（用户主动点下载才联网），也是对审核最友好的形态——主动交代边界，
   比被审核员发现「有网络行为但商店截图没说」再解释便宜得多。注意这与 1.0.3
   的「朗读过程中没有任何网络请求」不矛盾：合成确实全程离线，联网只发生在
   用户主动触发的音色包下载这一步，且由系统服务执行。
2. **不提技术名词**：不写 Core Speech Kit、person 21 这些，用户视角只有
   「多了一个男声、要下载、下完能离线用」。
3. **「零权限」重申**：与 1.0.3 隐私条形成连贯口径；这版动了下载链路，
   更需要主动压住「它是不是要联网了」的疑虑。
4. **a11y 只给用户一句话**：读屏适配对普通用户无感，但复评维度里它是明项，
   写一条既诚实又不啰嗦。

## 附：技术备注（党哥留存，不上传）

- 音色下载：Core Speech Kit `textToSpeech.downloadVoice`（系统级下载，
  不牵 app INTERNET 权限）；ReaderPrefs 新增 `KEY_TTS_VOICE_DL` 落盘；
  两击确认模式（第一击 toast 明示系统服务+流量，第二击才发下载）
  ——AlertDialog confirm 重载不稳，弃弹窗走 toast+二击（仓内 Index.ets 先例）
- 自动续听：`onPageShow` 里 `speakActive && speakPaused && tts.state==='paused'` 时 resume
- 横屏：`LayoutStyle.formPadOf`（FORM_MAX_VP=560，版心单侧补丁，纯函数）
  + 四页 `@State padX` + 根节点 `onAreaChange`；`layout.test.ts` 补 3 条（182→185）
- 设置面板修复（模拟器实测抓到的真缺陷）：面板内容总高超抽屉本体时
  「点外部关闭带」被挤成 0 像素 → 头部加 ×、关闭带固定高度 SETTINGS_STRIP_VP=88、
  档位行进 Scroll、Scroll 改 layoutWeight（父高确定）
- a11y：Reader 12 处 + Index/Settings/About/Stats/Privacy 9 处 accessibilityText
- 隐私政策文档同步：第三节改「音色下载由系统语音服务执行」、
  第四节「没有申请任何权限」，与应用内 Privacy.ets 逐字对齐
- 装机验证：模拟器实测——播放条进度 18%→32%→81% 真推进、音色两击下载链路
  （模拟器缺凌飞哲音色包，失败优雅回退）、面板两条关闭路径均生效、
  书签 3→4、长按摘录保存、全文搜索按章出摘要
- 测试基线：reader 185/185 全绿；ArkTS debug 编译 BUILD SUCCESSFUL
