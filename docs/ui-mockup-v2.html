这一版落实的纪律

  • 正文绝不用点阵字 —— 数码（页码/进度/序号）用等宽，正文用系统字体
  • 阅读页零常驻控件 —— 只有一行页脚（章名 + 页码）
  • 不出现任何滑块 —— 字号/行距/边距全是 5 档芯片
  • 字体不进安装包 —— 系统字体可直接选（0 体积）；开源字体按需下载，存本机
  • 广告不参与布局 —— 阅读页永远零广告；广告缺席时不留空洞（M7）
  • 空态不放营销文案；任何屏幕都不出现滚动条

档位 → 数值（唯一真源）

  • 字号：14 / 16 / 18 / 20 / 22 fp
  • 行距：1.4 / 1.6 / 1.9 / 2.2 / 2.5 倍
  • 页边距：12 / 16 / 20 / 24 / 28 vp
  • UI 芯片只写序号，排版层查表 —— 不允许出现第二份数值
  • 切换档位后按字符偏移复原位置，不会跳页
