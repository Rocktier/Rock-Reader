## 〇、⚠️ 定位修正（党哥 2026-11-03 23:47 亲口，**优先级高于本文其余部分**）

> 「我需要做的是一个把**万物（基本上就是文档类的东西）转换成 Markdown** 的应用，是**一款转换应用加阅读应用**。」

这句话纠正了一个**很关键的偏**：我把「AI first / 给 AI 提供粮食」当成了产品品类，
于是把**体检（边白）**做成了整个界面身份的 signature。方向反了。

正确的身份顺序：

```
转换（万物 → 一页 Markdown）  →  阅读（读这一页）  →  体检（验证它没坏）
       ↑ 产品本体                    ↑ 产品本体            ↑ 一层能力，不是身份
```

由此必须改的四件事（**v2 设计稿按这条重审过再移植**）：

1. **入口不能只是"选文件 + 七条规则"**。要能看出「文档类万物」：一条格式带（docx/txt/csv/md 可用，pdf 在接），
   以及**"上次转的那个"入口** —— 阅读应用必须有地方回，否则它只是个转换器带预览。
2. **阅读屏从第四块板升为主角**。现在的阅读屏带着边白批注（"A4，读到这里会断"）——
   那是**校样**，不是阅读。阅读模式要干净：一页纸、无行号、无规则号、无黄色。
3. **同一个文件的两种看法**：`读`（渲染后的正文）与 `校`（源码 + 边白）。
   边白只在「校」里出现。这一条同时解决了"体检插在阅读里很吵"的问题 —— **隐喻不用换，只是收窄**。
4. **转出来的东西要留下来**（本地存 .md + 一个最近列表），否则「阅读应用」没有对象。**这是新增功能，需党哥拍板**。

⚠️ 派生结论：**PDF 必须早做**。「万物」如果只有 docx，这句话就是空话；PDF 是文档类里最大的一块。

## 一、为什么不是 Rock 家族的样子

党哥 2026-11-03 明确要求：**all2md 要保留自己的特色，不与 Rock 阅读 / Rock 私记一致。**
「一致」的最省事做法是换色号，但那还是同一个壳。所以这次换的是**材料**：

| | Rock 家族 | all2md「边白」 |
|---|---|---|
| 底 | 纯黑 `#000000` | 校样纸 `#E9EBE1` |
| 字 | 白 | 墨绿黑 `#16211B` |
| 强调 | 家族红 `#FF4A3D`（品牌色，可装饰） | 警示黄 `#EFAF39`（**只表示出问题，全案零装饰性黄**） |
| 圆角 | 只有 0 与 12 | 只有 2 与 8（像裁切误差，不像 UI 卡） |
| 字体 | HarmonyOS Sans | HarmonyOS Sans（**不打包等宽**，见下） |

**禁用于 all2md**：`#ff4a3d` 及邻近红、纯黑 `#000` 底、圆角 0/12 规则、`docs/tokens.css`（家族 token）。

## 二、隐喻与 signature

**隐喻 = 一页留了边白的校样（the margin）。** 正文照原样排，七个记号只写在边上；哪一处会让 AI 读错，边白先开口，并且指到那一行。

这个隐喻是从产品唯一不可替代的东西推出来的：**「错了你看得见」**。而"看得见"在纸上只有一个位置 —— 边白。
所以体检**不是**页面底部一排勾，是写在页边的记号。

**signature 三件套（拆了就散）**：

1. **七格色标条** —— 像印厂贴在纸边的控制条。失败不是"变红"，是**被抠掉**（条还在，中间少一格）。
   缩到 30% 也成立：一条黑里有个洞。
2. **行号让位** —— 出错那行的行号 `27` 直接换成规则号 `A4`。抽象结论钉死在一行字上，用户不用在页面里找对应。
3. **荧光笔只压字高中段** —— 不是整行反白，是"有人在纸上划了一下"。

## 三、四屏

| 屏 | 内容 | 关键点 |
|---|---|---|
| 入口 | 一句主话 + 一个按钮 + 七条规则清单（12fp 双列） | 七条不是功能列表，是「凭什么可信」的证据 |
| 转换中 | 逐块吐字 + 右侧步骤清单（还原标题层级 / 还原列表编号 / 表格转 Markdown / 七项体检） | **不用转圈**；⚠️ 见第五节 |
| 结果 + 体检 | 判定句「有 1 项会让 AI 读错」+ 七格条 + 带行号的源码 + 失败行的边白注 | 最重要的屏 |
| 阅读 | Markdown 渲染成正文（标题/表格/列表/图占位） | ArkUI 里还不存在，要从零写 |

## 四、五项裁决（2026-11-03，写进 `设计说明-v2.md` §8）

1. **A4 alt 不矛盾** —— 仓里两份样本：`test/samples/供应商接入须知.docx` 空 alt（**A4 FAIL**），
   `entry/src/main/resources/rawfile/sample.docx` 带 alt（七项全过）。设计画失败态是对的，判定逻辑不改。
2. **「转不了」文案改成「这个文件打不开」** —— 选择器已过滤后缀，真实常态是 `ConvertFailure.BrokenPackage`（加密/损坏/其实是 .doc）。
3. **不打包等宽字体** —— 实测 `hdc shell ls /system/fonts`：系统**没有任何等宽字体**，只有 `HarmonyOS_Sans*`。
   源码感靠：行号独立右对齐列 + 页边 1vp 竖线 + `|` 用 `--muted` 降一档色。行号可试 `'HarmonyOS Sans Digit'`。
4. **行号计空行，且必须现算** —— `markdown.split('\n').length`，不许把稿面上的 27 写死。
5. **入口七条保留** —— 真机嫌重就减字（只留名词），不减条数。

## 五、两个必须记住的风险

- ⚠️ **「转换中」比实现快**：设计画的是逐块吐字 + 逐条体检，当前是**一次算完再显示**。
  移植必须二选一：① 给 `DocxReader` 加进度回调（真做，工作量不大）② 退化成「结果已好的短入场」。
  **不许假装进度** —— 假装进度是欺骗，比没有进度屏更糟。
- ⚠️ **阅读屏一行代码都没有**：要从零写 Markdown 渲染器（标题/表格/列表/链接/图占位）。
