- `data/TrashStore.ets`（新，纯逻辑）：`TrashEntry / encodeTrash / parseTrash / sortTrash /
  remainingDays / expiredTrash / remainText`，保留 30 天。
- **回收站是独立加密容器 `trash.rkd`，不混进 `index.rkd`** —— 这是本版最关键的设计取舍：
  主索引有几十处读路径，只要漏一处过滤，已删日记就静默复活（不崩、只是见鬼）；

- `NoteStore.deleteEntry`：先 `rename` 到 `trash/<id>.rkd`，**成功才摘索引**；
  rename 失败返回失败（宁可删不掉，不留「索引没了、文件还在」的半截态）。
  新增 `listTrash / restoreEntry / purgeEntry / purgeAllTrash / autoPurgeTrash`；
  `clearMemory()` 一并清回收站（里面也有 preview）。
- `pages/Trash.ets`：日期 + 剩余天数 + 摘要；恢复 / 彻底删除（二次确认）/ 清空（二次确认）。
- 设置页「最近删除」入口**必须内联**（`settingRow` 是 @Builder 值参数，不随 @State 重跑，
