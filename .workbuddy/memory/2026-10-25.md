## 私记：四个实拍 bug（全部 dumpLayout 定位，非推测）

1. **统计页「每月字数」柱状图只渲染 1 个月**：item Column 无确定宽度，
   柱的 `width('100%')` 百分比循环回退到 Row 全宽 ⇒ 12 个月每个都占满行宽并排，
   只有第 0 个月（2025-11）在屏内，当月满柱被推到 x≈12000 外。
   修：item 加 `layoutWeight(1)`；柱区从 `Stack(alignContent:Bottom)`
   改 `Column(FlexAlign.End)`（原写法柱后画会盖住柱顶数字）；柱定宽 14vp。
2. **编辑已有日记后返回列表不刷新**：`noteRowKey = 'n:'+id` 不含「内容变了」
   的信号 ⇒ LazyForEach 不重建 item（冷启动才对）。修：key 带 `updatedAt + words`
   （`saveEntry` 两个都刷新）。本族第四次同型坑。
3. 月历空态 if 里现算 `.length` 不响应 → 显式 `@State monthEmpty`；热度 key 带 words。
4. Unlock 页 Scroll 内 `Blank()` 永 0 高 → Column 补 `.height('100%')` + margin。

## 华为 1.0.3 审核「可提升项」三条（API 24 / Pura 80 Ultra）

1. **跟随系统无变化**：`isDarkMode('system')` 返回 **null** ⇒ `null === true` 为 false
   ⇒ 跟随系统时色板**恒浅色**。修：新增纯函数 `resolveDark(mode, systemDark)`，
   `systemIsDark(ctx)` 读 `ctx.config.colorMode`；补 `EntryAbility.onConfigurationUpdate`
   让运行中系统切换也跟随（走 AppStorage 换对象，不调 setColorMode）。
2. **筛选 chip 看不出高亮**：选中态原 `#E3E6E8` vs 未选中 `#FFFFFF`（浅灰 vs 白）。
   改「墨底反白」（accent 底 + bg 色字 + 加粗）。
3. **标签要点第二次才高亮**：chip 的 ForEach key 带 `:on` 后缀即可根治；
   **收藏 chip 是直接调用 @Builder → 值参数不随 @State 重跑**，必须改 if/else 条件渲染
   （实测：点了收藏，列表筛了、chip 底色仍是白）。

## 今天的坑（新增）

- **@Builder 值参数不随 @State 重跑**：`this.chip(label, this.someState, cb)` 这种
  直接调用，@State 变了 UI 不一定重绘（ForEach + key 变化的那条路径却是好的）。
  解法二选一：① key 带状态强制重建；② if/else 条件渲染整段重建。
- **UIAbility 没有 `onConfigurationUpdate` 的 super**：ArkTS 能编译，`super.` 运行时抛错，
  表现为**窗口存在但内容全空（黑屏）** —— 排查时差点误判成色板改动炸了。
- **模拟器会自动锁屏**，锁屏后 `aa start` 报 `10106102 device screen is locked`，
  `screenCap` 拍到纯黑（66908 字节，看到这个字节数 = 黑屏）。
  解锁：`keyEvent Power` + `swipe 628 2680 628 700`（从最底边往上滑），
  但**滑动解锁不稳定**，会反复锁上 —— 别把黑屏当代码 bug。
- **dpr = 3.5，视口 ≈ 359vp**（不是 3.0/419vp）：心情条 8vp→28px、柱 72vp→252px 双证实。
- **release 出包命令**：`assembleApp` **不能带 `--mode module`**（报 00306054
  任务不存在）；正确写法 `assembleApp -p product=default -p buildMode=release`，
  产物落在 `build/outputs/default/*.app`（目录名是 product，不是 buildMode）。
- `hap-sign-tool verify-app` 的 `-outCertChain/-outProfile` 必须是**存在的本地路径**，
  传 `/tmp/xxx` 会报 11012005。
