## 模拟器自动化操作要点（下次直接照抄）

- 密码页用**安全键盘**，`uitest uiInput inputText/text` 走 IME 通道**不可靠**
  （会在末尾多写一个字符，且是追加、不清空）—— 别用。
- 正解：**`keyEvent <数字键ID>`**（0=2000，1=2001…9=2009）逐个敲；
  敲完先 `keyEvent Back` **收起键盘**，再点按钮。
  ⚠️ 否则点击坐标落在弹出的键盘按键上 = 又输入一个字符（我在这卡了 4 轮）。
- `inputText` 是**追加**语义，框里有残留会越输越长；清空靠冷启动（force-stop + start）。
- 键盘弹出时 `uitest dumpLayout` 里目标按钮会消失（被顶出可视区）；
  Select 弹层打开时 dump 直接报 "Get window nodes failed" ⇒ 弹层/系统 UI 一律用**截图**看。
- 模拟器约 30 秒无操作自动锁屏 → 解锁：Power 唤醒 + `swipe 628 2300 628 1200` 上滑。
- **编译绝不能带 `MSYS_NO_PATHCONV=1`**（会把 E: 盘路径转坏、编译静默失败），
  而 hdc 必须带。同一条命令里两者混用 ⇒ 装的是旧包（我因此误判过一次修复没生效）。
- 视觉模型报的像素坐标不可信（误差数百 px），坐标一律从 UI 树的 `bounds` 取。
