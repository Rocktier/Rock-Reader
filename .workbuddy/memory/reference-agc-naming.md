# AGC 应用名称与信息字段（2026-11-10 定案）

> 触发：私记 `2.0.0` 因「提交的应用名称与应用安装后终端显示的名称不一致」被拒，
> 引用《审核指南》1.20。桌面实证：模拟器图标下显示 **「Rock阅读」/「Rock私记」**，
> 中文品牌名、**不带任何副标题**。

## 一、规则原文与推论

来源 <https://developer.huawei.com/consumer/cn/doc/doccenter-submission/50104>

- **1.20**：「应用信息需与应用安装后的图标、名称、版本、开发者信息、应用内容一致。
  如果您的应用分发至全球多个国家或地区，提供的所有语言的应用信息同样需与……一致。」
- **1.1**：名称 ≤15 汉字 / 30 其他语言字符；上传名称须与软著证书的软件名称/简称一致。
- **1.2**：名称不得为广义归纳词、类别词、功能性描述词、热门搜索词；
  **不得在名称中堆砌 2 个或以上关键词**。
- **1.4**：名称不得含占位符、乱码、表情、特殊符号（原文示例 `* & - ( )`）。
- **1.12**：应用名称**一个自然年内可支持修改 2 次** ⇒ 每次改名必须一次改对。
- **1.14**：应用介绍不得含误导性、不相关或不恰当的商业化用语、热门搜索词。
- AGC《发布应用》原文：**「应用名称须与 APK 中的应用名称一致，
  否则可能会导致应用上架审核不通过」**。

⭐ **结论：副标题不能并进应用名称。**「本地私密日记 · 时间胶囊」/
「TXT / EPUB 本地电子书阅读器」全是功能性描述词 + 类别词 + 分隔符，
并进名称直接踩 1.2 / 1.4；还会与软著名称不符（1.1），并白耗一次年度改名额度（1.12）。
**包里不需要同步改**，因为根本不该整合。

## 二、AGC 后台确实没有「副标题」字段

《发布应用》与《配置可本地化基础信息》列出的可本地化字段只有四个：

| 字段 | 必填 | 限制 | 放什么 |
|---|---|---|---|
| 应用名称 | 必填 | ≤15 汉字；须与包内一致 | **只填品牌名**「Rock私记」/「Rock阅读」 |
| 应用介绍 | 必填 | ≤8000 字符 | 功能、定位、隐私口径；功能描述词放这里 |
| 应用一句话简介（小编推荐） | 必填 | 中文 ≤17 字符（HarmonyOS 文档口径） | 最凝练的一句卖点 |
| 新版本特性 | 选填 | 中国大陆 ≤500 字符 | 本版更新说明 |

另有「应用分类及标签」放检索词。官方导航名（文档原文）：
HarmonyOS 开发者中心 →「应用管理」→ 左上筛选应用 → 左侧「应用上架 > 版本信息」下待发布版本
→「可本地化基础信息」区域 → 选语言填写。
⚠️ 后台实际界面若与这段导航名不符，**截图确认再点，不凭路径猜**。

⭐ 我写的文案里「副标题」那一行是**内部策划短句，不是可填字段** —— 这是文档缺陷，
党哥照着填才出事。其内容拆解：凝练短句 → 一句话简介；
功能词（本地私密日记 / 时间胶囊 / TXT / EPUB）→ 应用介绍正文 + 关键词标签。

## 三、包内名称链（中文环境实测）

| | `app.json5` label | ability label（zh_CN） | 桌面图标文字 |
|---|---|---|---|
| 阅读 | `app_name` zh_CN = Rock阅读 | `EntryAbility_label` zh_CN = Rock阅读 | **Rock阅读** |
| 私记 | `app_name` = Rock私记 | `EntryAbility_label` zh_CN = Rock私记 | **Rock私记** |

- `base` 目录里是英文名（`RockReader` / `RockJournal`），
  中文由 `resources/zh_CN/element/string.json` 覆盖 ⇒ 中文环境桌面显示中文品牌名。
- 桌面图标名取 **ability label**（家族已知「桌面图标取 ability icon」，名称同理）。
- 判据：**AGC 应用名称 == 桌面图标文字**，逐字一致，不加任何后缀。
- 若真要改展示名，须同改 `AppScope/app.json5` + base/zh_CN 的 `app_name`
  + `EntryAbility_label`（含桌面卡片 label），并**重出包 + 递增 code**（本次不需要）。

## 四、本次修复与纪律

- 拒审根因：党哥在 AGC「应用名称」里把副标题一起填了 ⇒ 与桌面「Rock私记」不一致。
- 修复：**只把 AGC 应用名称改回「Rock私记」**，副标题内容移到一句话简介 /
  应用介绍 / 关键词；改完重新提交审核。
  **包不用改、不用重出包、不用递增 `versionCode`**（包内名称本来就对）。
- ⭐ 纪律：文案文档不得再把「副标题」列为可填字段；每次提交前用
  「AGC 应用名称 vs 桌面图标文字」逐字比对一次；名称改动占 1.12 年度额度。
- 阅读 `2.0.0` 已过审，但其 base 名称同样是英文，中文环境靠 zh_CN 覆盖；
  若以后分发非中文语言，需补对应语言的 `string.json`，否则 1.20 多语言一致性会踩坑。
