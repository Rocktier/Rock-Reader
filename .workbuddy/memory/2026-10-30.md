## 三、本轮踩到/规避的坑

- **MSYS 路径拼接**：Git Bash 里 `hdc install F:\...` 会拼成
  `F:\cwd\F:/...` ⇒ 报 no such file。**一律用 PowerShell 工具调 hdc**。
- **git add 警告 LF→CRLF**：本仓 core.autocrlf=true，新建文件会转 CRLF，属正常。
- **P0-2 刻意不做浮层**：新浮层 = 新影子状态（滚屏守卫要改纯逻辑函数+单测）。
  改成**行内编辑**后，滚屏守卫只需管已有的 showToc ⇒ 零新增状态机。
- **P0-3 与进度同源**：`bookLeftChars` 用 percent 反推已读字数，
  与 `bookPercentOf` 同一口径 ⇒ 不会出现「进度 62% 但剩余算出负数」。
- **ForEach key 变化位**：摘录 key 带 `color`、书签 key 带 `note`、
  网格卡 key 带 `author` —— 少带一个就会「数据变了 UI 不变」（家族铁律第 6 次）。

## 四、党哥反馈的两处修正 + 1.0.9 出包

党哥看完 P0 提了两点，都改了，随后出包 **1.0.9（code 1000010）**。

1. **摘录色标太长**：`Column().height('100%')` 吃满整个 ListItem（含「第 N 章」与
   行 padding）⇒ 竖线 70+vp，像分隔线。改固定 **20vp + alignSelf(Start)**。
   ⇒ 教训：列表里的装饰性竖条**不能用 '100%'**，要固定高度。
2. **正文不能长按选文字**：Text 没有 `copyOption` ⇒ 长按只触发摘录手势，拖不出手柄。
   加 `.copyOption(CopyOptions.LocalDevice)`。

### ⚠️ 划词选中的能力边界（查了 SDK d.ts，别再试第二次）

- `SelectionContainer` 在本工程 **compileSdk 20 下编译不过**
  （`ArkTS: Cannot find name 'SelectionContainer'`，ERROR 10505001）
- `onTextSelectionChange`（取选区文本）与 `editMenuOptions`（往系统菜单塞自定义
  「摘录」项）**都是 API 26 起** ⇒ 本工程 20 用不了
- ⇒ 只有 `Text.copyOption` 一条路。想要「摘录正文里某一句」，
  只能把摘录面板里的原文从 Text 改成 **TextArea 让手动裁剪**
  （`highlightExcerpt` 因此由 private 改 @State）。

### ⭐ 出包脚本的 stderr 坑（家族级，两仓都已修）

`build-release.ps1` 开头 `$ErrorActionPreference = "Stop"`，而 **hvigor 把 WARN
也写到 stderr**。原先 `node ... 2>&1` ⇒ 原生命令的 stderr 被转成 ErrorRecord，
Stop 下**当场中断** ⇒ 表现为「**6 秒就 Failed :entry:default@CompileArkTS**」，
看着像编译失败，**其实构建根本没跑完、产物目录还是旧的**。
按记忆铁律「无信息失败先重跑」重跑一次仍然失败 —— 这次不是偶发。
⇒ 修法：经 `cmd /c` 重定向 + 只看 `$LASTEXITCODE` 判成败（两仓已同步）。

**新判据**：出包「几秒就失败且日志无 ERROR 行」时，先看**产物目录时间戳**
—— 没更新就说明构建压根没跑完，别急着重跑。
