# 产品对标与迭代路线（Rock 家族）

> 从 MEMORY.md 拆出（2026-10-28，因主文件超注入上限）。
> 主标杆 Day One，党哥 2026-10-27 拍板记入。

## 七、产品对标与迭代方向（Rock私记 vs 标杆）

**主标杆 Day One**（Apple Design Award / 4.8 分），辅参照 Journey / Diarium / Reflectly。

**已做到（当卖点讲）**：① 加密强度反超免费标杆（AES256-GCM + PBKDF2 10 万次全量本地加密；Day One 免费版仅传输加密）；② **时间胶囊独占护城河**（写给未来的信，到期前连自己都不能读，硬封存不剧透字数/心情/摘要；Day One 无此能力）；③ 统计与洞察扎实（连续天数/最长连续、月字数柱状图、心情分布、月历热力图、那年今日、时间轴、全文+标签搜索、筛选）；④ 数据可携（加密备份 `.rkdbak` + TXT/Markdown 明文导出 + 容错导入）；⑤ 富文本块模型、一天多篇、心情、收藏、标签、桌面卡片、深色模式齐全。

**差距分级**
- **A 类 · 本地就能做，零联网（优先）**：① 语音转文字 ✅ **1.0.6 已实现**（离线 ASR；只落文字不存音频；真机准确率待验）② 位置标签（`@kit.LocationKit`）⬜ ③ 写作提醒（本地推送，把"偶尔写"变"每天写"）⬜ ④ **Markdown 双向 ✅ 2026-11-05 已做**（`data/MarkdownImport.ets`，导出的 `.md` 能读回来，见当日日志；待进 **1.0.11**）⑤ 模板库深化 ✅ 1.0.6 已做自定义模板 ⑥ 多日记本 ✅ 1.0.6 已做 ⑦ PDF 导出 ⬜ ⑧ 每日提示 ✅ 1.0.6 已做
- **B 类 · 需联网，与"非主动联网"冲突（主动取舍，不是落后）**：云同步、云端 AI 回顾、IFTTT 导入。
- **C 类 · 我们领先（卖点）**：全量本地加密、时间胶囊硬封存、完全离线、自研 JSON 十年可读、不绑云账号。
- **坚决不做**：云同步 / 云端 AI —— 守住"数据完全自持"这个与标杆最大的差异化。

## 八、剩余 A 类两项有个共同前提（2026-11-05 核实）

② 位置标签、③ 写作提醒 **都要新权限**（`LOCATION` / `NOTIFICATION` 系），
按第二节纪律：**新权限必须在同一提交内改完隐私政策与 AGC 说明**，不能顺手做。
而且两者都要真机/模拟器才验得出（定位、通知到点弹不弹），不适合"不开模拟器"的场景。

## 九、Rock阅读侧的诊断（2026-11-05 据代码核实，不是凭印象）

**已经齐了**：全文搜索、书签、摘录、目录、主题、翻页、亮度 6 档、常亮、字体族、
简繁转换、TXT 去广告、朗读 TTS（含音色/语速）、自动滚动、统计（连续/成就/本章与全书剩余）、
每日阅读目标（`DAILY_GOAL_STEPS` 0/10/20/30/60，默认 20）、每本书独立排版。

⇒ **阅读器不再是"功能不够"，而是"剩下的活都要用眼睛验"**：
- **EPUB 插图**：`pages/Reader.ets` 里与图片相关的命中几乎为零 ⇒ 书里的图现在读不出来。
  这是对照 Apple Books / Kindle / 静读天下最明显的一处硬差距，
  但要解压取图 + 落沙箱 + 渲染，且**必须看效果**，不开模拟器做不了。
- **阅读进度条**（视觉）
- **翻页动画**（仿真/滑动）

结论：阅读侧下一步该在**能开模拟器的时候**做 EPUB 插图，而不是现在硬写。
