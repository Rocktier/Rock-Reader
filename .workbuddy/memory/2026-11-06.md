## 二、all2md 深色模式做完（HIG 唯一未达标项补齐）

**页面里零 `if (isDark)`，156 处调用点一行未改。**

### 三个只有装机能发现的问题

1. ⭐⭐ **资源 color 的 8 位 hex 会被静默吞成透明**。`"#00000055"` 编译过、包里有、`$r()` 也解析得出，
   但运行时完全不挡。发现方式是抽屉打开时采样像素：抽屉 `(29,35,31)` 对、遮罩区 `(19,24,20)` ≈ 页面原色 `(20,24,21)`。
   **这个 bug 在浅色模式下一直存在**，初版就写着 `#00000055`，没人注意过。
   ⇒ 资源色只能 6 位；透明度写组件的 `.opacity()`。

2. ⭐ **深色下"遮罩压暗"没有空间**。页面只有 8% 明度，压 72% 黑后两块糊在一起。
   ⇒ 新增 `sheet` token：深色浮层比纸**亮一档**（`#1D231F`），高度靠抬起表达。
   **浅色靠压背景分层，深色靠抬浮层分层。**

3. **按压态方向两套必须一致**。初版深色 `paper_3_down` 写成比常态亮，被单测拦下
   —— 同一按钮两套手感相反，用户切过去会觉得按错了。统一"按下总是变暗"。

### 配色判断（不是反相）

纸 `#141815`（保留绿调，非纯黑）、墨 `#E4E8DF`（非纯白，14.6:1）、
荧光笔黄两套同值（语义色不随主题变味）、警示文字和链接深色反向提亮。

## 八、书架封面：识别补齐 + 续读卡封面不换（21:20）

党哥问「阅读应用能不能把书本的封面加上去，如果原文件带有封面的话」。

**先纠正一个前提**：封面不是没有，9 月就做了（上架截图 `docs/store-screenshots/01-shelf.png`
里那本《暗恋·橘生淮南》就是真实封面）。他当时书架上是 3 本 TXT 测试书，
TXT 本来就没有封面，所以整屏都是首字占位 —— 看起来才像"没这个功能"。

### 补上的两条真实写法（`Opf.ets`，纯逻辑，+12 条单测 → 361/361）

| 写法 | 原来 | 现在 |
|---|---|---|
| EPUB3 `properties="cover-image"` | ✅ | ✅ |
| EPUB2 `<meta name="cover">`（content=id） | ✅ | ✅ |
| 同上但 **content 被写成文件名** | ❌ 按 id 找必然落空 | ✅ 再按 href/文件名找一次 |
| EPUB2 `guide` 指到**一页 XHTML** | ❌ 把 HTML 字节当封面写（静默空白） | ✅ `coverImageOfPage()` 抠 `<img src>` / SVG `<image xlink:href>` |
| 什么声明都没有，只有 `cover.jpg` | ❌ | ✅ 命名启发式（0/2/3 分级打分） |
| MOBI / AZW3 的 EXTH201 | ✅ | ✅（另加文件头校验） |

- 启发式**只认图片 + 扩展名**，文字/音频哪怕 id 含 cover 也不认；同分取先出现的
  （manifest 顺序≈作者建书顺序，正封在前）；`cover.jpg`(3) 赢过 `cover-thumb.jpg`(2)。
- 新增 `engine/importer/CoverImage.ets` 的 `isImageBytes()`（按文件头认 jpg/png/gif/webp/bmp），
  `writeCoverBytes` 一律先验再写。**MOBI 封面是按记录号算的，算偏一位会取到文本记录** ——
  写一张解不出的图比不写更难查（两者在书架上长得一模一样）。

### 修掉一个真 bug：续读卡片封面不随书切换

- **症状**：导入一本带封面的新书后，卡片**书名换了、封面还是上一本的首字占位（一个 g）**，
  杀掉重进才正常；网格里却是对的。
- **根因**：`bookCover(book, size)` 是**带值参数的 @Builder**，里面的 `if` 分支条件读的是
  **参数**而不是 @State ⇒ V1 分支按首次求值定型，参数变了也不重判。
  网格没这问题纯属走运：换 ForEach 键会重建节点，首次求值恰好拿到新书。
- **修法**（家族铁律原话「把条件挪到读 @State 的地方」）：新增 `@State resumeCover`，
  `load()` 里与 `resume` 一起算好，卡片里就地展开 Image/占位两支。**别改回复用 @Builder。**
- 同型第 8 次。教训升级：**带值参数的 @Builder，只要里面还有 `if`，就不能碰 @State 派生的东西** ——
  不只是"刷不刷新"的问题，是**分支被定死了**。

### 装机验证（造数方法，下次直接用）

- 用 System.Drawing 画封面 JPEG + python `zipfile` 造 4 本样书，覆盖四种写法
  （`cover-a3` 声明型 / `cover-b2` 封面页 / `cover-c4` 裸文件 / `cover-d0` 无封面）。
  ⚠️ Windows PowerShell 5.1 读 UTF-8 **无 BOM** 的 .ps1 会乱码并把引号解析搞错
  ⇒ 生成脚本里只写 ASCII。
- 推设备：`MSYS_NO_PATHCONV=1 hdc file send x.epub /storage/media/100/local/files/Docs/Download/x.epub`
  （**不带 MSYS_NO_PATHCONV 会被改写成 Git 安装目录下的相对路径**，报 no such file）。
- 截图：`uitest screenCap` **不接受指定文件名**，输出路径在 stdout 里（`dumpLayout` 同理），
  必须 grep 出来再 `file recv`；`file recv` 的本地路径写**相对名**。
- 结果：声明型 / 封面页 / 裸文件三种都显示真实封面，无封面那本仍回退首字 —— 与设计一致。
  归档 `docs/ui-preview-2026-11-06/阅读-书架-封面-子夜.png`。
- picker 路径实测坐标（1256×2760）：`＋(1133,241)` → `浏览(743,289)` →
  `下载与接收(630,1993)` → `下载管理器(1014,693)` → 文件栅格首行 y=1054、三列 x=240/627/1014。

### 没做

- **PDF 首页当封面**：`PdfPage.getPagePixelMap()` 存在（`@hms.officeservice.pdfservice.d.ts:2527`），
  技术上能做，但**本地 x86 模拟器没有 PDFKit（`canIUse` false）**，写了我无法自证能跑。
  书架上多一张缩略图是锦上添花，不值得塞盲代码 —— 留到有真机的那一版。
- **老书补封面**：封面是导入时抽的。旧书当年若抽失败（正好是上面那两类写法），不会自己重抽，
  只能「移除后重新导入」，或者下一版加一个按版本号跑一次的补抽。判断不急
  （唯一实测过的真实书《暗恋·橘生淮南》当年就有封面），**待党哥拍板**。
- TXT / MD / HTML 永远没有封面（原文件里就没有）⇒ 仍是首字占位。可选的下一步是
  "拿书名排一张文字封面"（Apple Books 的做法），**没做** —— 党哥原话是"原文件带有封面的话"。

### 四条可复用的判断

- ⭐ **字号不达标改 token，不改调用点**：阅读 67 处、私记 62 处，逐处改是同一件事做 62 遍。
  代价是要处理折行副作用（11fp 放不下会甩孤字，如设置页「a）」），改成**显式断行、断在语义边界**。
- ⭐ **主按钮的字色不是 `bg`**：`fontColor(palette.bg)` 是"拿页面底色当字色"，
  语义上跟着主题漂。护眼主题的底是豆沙绿/米黄 ⇒ 压蓝底只有 4.3。
  正确做法与 heroBg/heroText 同款：**再立一对 `onAccent`**，四套主题各给值。
- ⭐ **热区比视觉重要，但热区不能压到邻居**：私记删除角标视觉 24、热区 40 而不是 44 ——
  缩略图间距只有 8，相邻中心距 72，44 会串到隔壁那张。**"推荐 44"要让位于"不与邻居重叠"**。
- **HIG 的"不只靠颜色"落到代码上就是三件事**：加字重/形状、加 accessibilityText、加数字。

### 「减少动态效果」—— 查证结果（欠了一轮的账，这轮还上）

**API：`settings.display.ANIMATOR_DURATION_SCALE`**（`@ohos.settings`）。
d.ts 原话：「If the value is 0, the animation ends immediately. The default value is 1.」
系统的「移除动画」就是把这个倍率压到 0。

- ⚠️ 标注 **@deprecated since 21**；我们 compileSdk 20 暂不受影响，**升 21 必须回来换**。
- ⚠️ **必须拆两个文件**：纯函数（`isReducedMotion`）进 `Motion.ets`/`Motion.ets`，
  SDK 读取进 `SystemMotion.ets` —— 引了 `@ohos.settings` 或 `$r()` 的文件进不了 node:test。
  all2md 一开始把纯函数塞进 `Tokens.ets`（顶层有 `$r`），测试直接 `$r is not defined`。
- ⚠️ **`Number('')` 是 0 不是 NaN**：不显式挡空串，"读不到"会被判成"用户关闭动画"
  ⇒ 整机动效静默消失，而且看着像设计决定。**单测抓到的，不是想出来的**。
- 降级时**连 setTimeout 都不排**（alpha/位移闪一帧 = 内容闪一帧）。
- 验证：hilog 打一行 `anim scale=1`，阅读与 all2md 装机实测读到（没走 catch）。这是唯一观测手段。

### 没验到的（如实记）

- **私记首页 / 统计页 / 编辑器**：模拟器停在解锁页，没有主密码 ⇒ 只验到"编译通过、启动不崩"。
- **阅读排版面板**：正文点击呼不出菜单（`uitest uiInput click` 在这个页面不生效，
  疑似 PanGesture 抢事件），面板的 44 行高与底部 32 padding **静态可信、未眼见**。
- **字体放大 200%**：模拟器没有改字体大小的命令行入口，未测。
- **把系统「移除动画」真的打开**：同上，无法在模拟器上制造该状态。

### 顺手修的既有问题

- 阅读排版面板最底部「主题」行贴手势条点不中 ⇒ 面板容器加 **32vp 底部安全余量**。
  不用 expandSafeArea 动态取：手势条 16–28vp，32 是覆盖全机型的静态上界，代价只是少 32vp（内部是 Scroll）。
- 书架网格入场去掉 `opacity`（只留位移），与续读卡一致 —— 铁律落实，此前网格漏了。
