# 应用图标：包内资源 vs AGC 单独上传（2026-11-06 定）

## 一、两套东西，别混

| | 包内资源（Launcher 用） | AGC 商店图标 |
|---|---|---|
| 形态 | **分层**：前景 PNG(带透明) + 背景 PNG(**禁止透明**) | **单张合成图**（系统不会替你叠层） |
| 尺寸 | 1024×1024 正方形 | **216×216 或 1024×1024**（AGC 原文两档） |
| 圆角 | **不许自己加**（系统自动遮罩裁切） | 同：华为规范口径是"无需圆角" |
| 位置 | `AppScope/resources/base/media/` | AGC 后台**单独上传字段**，不从包里取 |
| 引用 | `layered_image.json` + `module.json5` 的 **ability** `icon` | — |

⚠️ **包内图标不生效只查 `module.json5` 里 ability 的 `icon`**（曾经 6 次换图不动，就栽在这；
`app.json5` 的 icon 管不着桌面）。

**三仓一致（2026-11-07 补齐 all2md）**：Reader / Journal / all2md 的 ability `icon`
全部指向 `$media:layered_image`。`startWindowIcon` 仍各指 `$media:startIcon`（启动页资源），
但 **startIcon 的内容必须＝前景+背景逐像素合成**，否则启动页与桌面是两张脸。
all2md 的 `startIcon` 原是 512 P 模式老图，已换成 512 RGB 合成图；背景层同时去掉 alpha 通道。
⇒ 判据：改动任一层，要连带重出 startIcon 与 AGC 成品图。

## 二、官方硬约束（原话）

- 图标资源**必须为正方形图像，无需圆角**，系统会为对应场景自动生成遮罩裁切。
- **背景图不允许含有透明像素**；自行裁圆角或加透明内边距 ⇒ 判"未正确分层"。
- 背景：手机/平板**纯色或简单渐变**、无复杂图形；电脑/智慧屏可微立体。
- 前景：非核心区 **100% 透明**，只留核心图形；**不宜过于靠近四角**（圆角会切）。
- 成品格式：PNG ≤3 MB；WEBP ≤100 KB。
