### 6. ⭐ 拦下第二个风险：release 混淆会打断 ASR 回调
`AsrService` 里的 `RecognitionListener` 是**系统接口的字面量实现**，五个方法名
（onStart/onEvent/onResult/onComplete/onError）由系统 SDK **按名字回调**。
属性混淆一旦改名 ⇒ 语音功能**静默失效**（能点、能进「在听」、永远等不到文字、零报错）。

处理：`entry/obfuscation-rules.txt` 加
```
-keep
./src/main/ets/data/AsrService.ets
```
这与已有的「序列化字段保护」是同一类风险（跨模块按名契约），只是过去只想到 JSON 字段。
