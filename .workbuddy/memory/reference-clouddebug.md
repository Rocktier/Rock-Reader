# AGC 云调试实战（2026-11-04 首次跑通）

> 入口：AGC 控制台 → 云调试 → 选机型 → 设备画面 + 右侧「应用 / 控制参数 / 截屏 / HiLog」页签。
> 本文只记**会反复咬人**的东西。验过什么 ⇒ `reference-releases.md` / 各应用 `progress.md`。

## 一、⭐ 密码框黑屏不是 Bug，是系统隐私保护（最容易白查一天）

**现象**：真机（或云调试投屏）上，焦点一进 `InputType.Password` 输入框，**整个画面变黑**；退出焦点立刻恢复。

**官方原话**（华为开发者论坛，2026 前后多次答复）：

> 密码输入框会使用到华为安全键盘，当焦点处于密码输入框时，**当前窗口为隐私状态**，
> 此时禁止截屏/录屏，**投屏时的确是黑屏的**；当焦点不处于密码输入框时，窗体处于非隐私状态，此时支持截屏或录屏。

- 系统对 Password 输入框**自动**加 SECURE 标志，不是我们设的（应用侧对应接口 `setWindowPrivacyMode`）。
- 官方拿**微信密码登录页**复现过同样现象 ⇒ 与我们的代码无关。
- **模拟器不复现**：模拟器没有硬件级安全隔离，跑不到这套逻辑。所以"模拟器正常、真机黑"是这个机制的标准指纹。

**⭐ 反着用**：这个特性可以当传感器。
盲测「锁定时长」时根本看不见画面，但 **黑屏本身就是「要密码了」的判据** ——
切回后台变黑 = 已锁；正常显示 = 未锁。比截图比对快得多。

**注意**：黑 ≠ 我们的背景色。日记浅色主题背景是米白 `#FAF8F3`、深色是 `#000000`。
若浅色主题下看到纯黑，第一反应应该是"窗口被 SECURE 屏蔽"，**不是**"内容被裁掉/页面崩了"。

## 二、Shell 页签执行的是**设备端命令**，不是 PC 端 hdc

页面提示写着「例如测试主页: input keyevent 3」，容易误以为是 hdc。

| 类型 | 可用性 |
|---|---|
| `bm dump -n <bundle>` / `aa start` / `ls` / `cat` / `cp`（同权限内）/ `uitest uiInput click x y` | ✅ 可用 |
| 管道 `\|`、重定向 `>` | ❌ 报「无效命令或被限制执行！」 |
| `input keyevent 3` | ❌ `input: inaccessible or not found` |

⇒ **切后台用设备画面底部的虚拟主页键**（三个虚拟键 ◁ ○ □ 中的 ○），不要指望 `input`。
⇒ 需要看长输出时没法 grep，只能肉眼看，或改用连 `-p` 参数 dump 文件再想办法取。

## 三、往设备里灌文件：三条路全堵（2026-11-04 实测）

验「阅读器导入」这类功能时撞上的墙，记下来省得再试一遍：

| 路径 | 结果 |
|---|---|
| `/data/local/tmp/` | 应用**读不到**（shell 的地盘，应用沙箱 uid 跨不过 SELinux）⇒ 界面报「读取文件失败」 |
| `/storage/media/100/local/files/`（公共文档） | shell `cp` 报 `Permission denied`；**但 picker 看得见**（走媒体库服务，不是文件系统） |
| 应用沙箱 `/data/app/el2/100/base/<bundle>/` | shell 能 `ls`，**不能 `cp`**（写被拒） |
| 「推送图片」页签 | **只收图片格式**，`.txt` 直接拒 |

**结论**：需要用户选文件的功能（阅读器导入书籍、文档转换），**云调试验不了**。
想验只能在真机上做，或者接受"这条链路只能本地模拟器验流程、真机验权限"。

⚠️ 但有个副产品：`aa start -U file://... -A ohos.want.action.viewData -t text/plain` 能**把任意 want 塞进应用**，
即使文件读不到，也能验「want 解析 + 错误提示」这条链路（我们就是这样确认「读取文件失败」文案是准的）。

## 四、没有麦克风通道

云真机不采集音频。ASR 只能验到「**引擎创建 + 开麦成功**」这一步：

- 点语音后**状态栏出现绿点** ⇒ 麦克风权限已授予 + 正在使用
- 界面进入「语音转文字中…」+ 出现「取消/静音」⇒ `createEngine` + `startListening` 都成功了

**这已是从未有过的好结果**：模拟器上 `canIUse` 直接 false，连引擎创建都到不了。
剩下"有没有声音进来"属环境限制，不该判为失败。

## 五、时间、签名、日志

- **单次 20 分钟，可延长一次至 40 分钟**；官方口径每人每天 24 小时，论坛客服说过 4 小时 —— **以界面实时余额为准**。
- ⚠️ **退出即重新分配设备**，设备上的数据（建好的库、导入的书）全部丢失 ⇒ 一次连上就把要验的一次做完。
- **debug 签名包能装**（`bm dump` 里 `appProvisionType: debug` 装得上），不必打 release 包。
- **HiLog 经云端转发有延迟**（几秒到十几秒），日志刷得比操作慢。**别等日志**，界面表现通常更快更准。
- ⚠️ **缓冲会被冲掉**：系统日志每秒几十条，几分钟前应用打的日志早被挤出缓冲 ⇒
  回头搜关键字会得到「暂无数据」，**这不等于没打日志**。
  抓日志的正确姿势：**先点「停止」冻结滚动，再在搜索框输关键字**（如 `asr`），
  顺序反了永远搜不到。要抓某次操作的日志，就得**操作完立刻停止**再搜。
- ⇒ 验收一律**以界面为准**（绿点、按钮态、`已保存 · HH:MM`、页面停在哪儿），日志只作补充证据。

## 六、云调试能验什么 / 不能验什么

| ✅ 能验 | ❌ 验不了 |
|---|---|
| UI 布局、裁剪、溢出 | 文件导入类（见第三节） |
| 交互状态机、浮层层级 | 音频输入（ASR 实际转写） |
| 持久化（编辑器底部「已保存 · HH:MM」就是铁证） | 跨设备/多端场景 |
| 权限弹窗与授权后行为 | release 专属风险（混淆测不出，debug 包没混淆） |
| 深色模式、真机尺寸下的排版 | 性能长跑 |
| 系统能力可用性（`canIUse`、引擎能否创建） | |
