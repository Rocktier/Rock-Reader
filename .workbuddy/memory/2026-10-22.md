## hdc 使用经验（下次直接复用）

- hdc 在 `E:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe`；
  Git Bash 下必须 `export MSYS_NO_PATHCONV=1`（否则 /data/... 被转成 Git 路径）。
- 编译**不能**带 MSYS_NO_PATHCONV（会把 E: 盘路径转坏），hdc 与编译分开跑。
- 截图 `snapshot_display -f /data/local/tmp/x.jpeg`（**后缀必须 .jpeg**）；
  `file recv` 的目标路径用**相对路径**（绝对路径会被拼到 cwd 后面报错）。
- 拿控件树：`uitest dumpLayout -p /data/local/tmp/x.json` → recv → python 解析
  （读 attributes.text / bounds）；点击 `uitest uiInput click x y`；长按 `longClick`；
  文本 `inputText x y text`（IME 通道，安全键盘下不可靠）。
- 模拟器 shell 权限不足：应用私有目录（database/）读不到；**没有 wm 命令**。
